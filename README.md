# NicoList - 動画リスト拡張

> [!NOTE]
> これは [Hallkun19/NicoList](https://github.com/Hallkun19/NicoList) の Fork 版（v1.2.1〜）です。upstream のクレジットと MIT ライセンスは元のまま残しています。
> **Fork版の変更点**
> - **リスト共有を無効化** — upstream の共有API（作者の Cloudflare Worker）へは一切通信しません。大画面ビューの共有ボタン／共有読込ボタンも外してあります
> - **更新確認先をこのForkへ変更** — 版数の確認と更新案内のリンクは kokenamazu-boop/NicoList を指します

ニコニコ動画・YouTube に対応した、ブラウザ上で動画をリスト管理できる Chrome 拡張機能です。
> [!WARNING]
> この拡張機能は、ニコニコ動画及びYouTube公式の拡張機能ではありません。
> 本ツールは個人利用を目的としており、プラットフォーム側の仕様変更により利用できなくなる可能性があることがあります。
> 利用によって生じた損害には、一切責任を負いません。


> [!NOTE]
> [友人](https://www.nicovideo.jp/user/132889643) がAIで作成した拡張機能の開発を引き継ぎました。
> そのため大半がAIで生成されているコードになっています、不備などがあったら随時修正していきます

## 機能

- **リスト管理** — 複数のリストを作成し、動画を自由に追加・削除・並び替え
- **メモ機能** — リストに登録した動画に、いろいろなメモを追加可能
- **クイック追加** — 動画ページのボタンからワンクリック／ダブルクリックでリストに即追加
- **検索ページから追加** — 【Fork版で追加】検索・タグページのサムネイルにホバーで追加ボタンを表示。クリックでデフォルトリストへ即追加（未設定時はリスト選択）
- **タグミュート** — 【Fork版で追加】設定に書いたタグが付いた動画を、検索・タグページで完全に非表示にします
- **マイリスト数表示** — 【Fork版で追加】検索・タグページのサムネイル左下にマイリスト数を表示
- **マイリスト数フィルタ** — 【Fork版で追加】マイリスト数がしきい値未満の動画を検索・タグページで非表示にできます
- **ニコニ広告を隠す** — 【Fork版で追加】検索・タグページで「提供：」表示のニコニ広告カードを非表示にできます（設定でON/OFF、初期ON）
- **あとで見る対応** — 【Fork版で追加】公式の「あとで見る」ページでもサムネイルに追加ボタンが出ます。ページ単位の一括追加ボタンもあります
- **検索ページのクイック追加** — 【Fork版で追加】検索ページでは、一度リストを選ぶとそのページを開いている間は同じリストへワンクリック即追加。右クリックで追加先の切り替え、追加直後はトーストから取り消しできます
- **連続再生・シャッフル再生** — リスト内の動画を順番またはランダムに連続再生
- **大画面ビュー** — 新しいタブで全画面リスト表示（グリッド／リスト切替・ソート対応）
- **リスト共有** — 【Fork版では無効化】upstream では短いコードでシェアが可能でしたが、このForkでは無効化しています
- **動画情報の自動取得** — 再生数・いいね数・マイリスト数・投稿日・サムネイルなどを API から取得
- **情報更新** — ボタン一つでリスト内の動画情報を一括再取得
- **インポート / エクスポート** — JSON 形式でリストデータを保存・復元

## 導入方法

1. [Releases](https://github.com/Hallkun19/NicoList/releases/latest) から最新の ZIP(NicoList_vX.X.X) をダウンロード
2. ZIP を展開
3. `chrome://extensions` を開く
4. 右上の「デベロッパー モード」を有効化
5. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを選択

## 使い方

### 動画をリストに追加

1. ニコニコ動画または YouTube の動画ページを開く
2. プレイヤー付近に表示される **NicoList ボタン**をクリック
3. 追加先のリストを選択

> [!TIP]
> 設定でデフォルトリストを指定すると、ダブルクリック（または設定でクリック）で即追加できます。

### リストの共有

【Fork版では無効化】このForkでは共有機能を使いません。
